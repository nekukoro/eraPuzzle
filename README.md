# 元号パズル
- 「元号の元年の西暦」: 「令和」なら,その元年(=令和1年)時点での西暦である2019年を指します。
- その元号が何周年か: 今年からそれぞれの元年を引いた値を表示します。(例: 昭和は元年が1926年なので、2026年は昭和100年(100周年)にあたります。)
  - 基準になる西暦は自由に変更することができます。

## 遊び方
1. 「ゲーム開始」を押すと5枚の元号カードが出現します。
1. カードをフィールドエリアへドラッグ＆ドロップ（またはクリック）して移動させます。
1. 「現在の選択合計」を「目標の数値」にできるだけ近づけてください。
1. 「確定」を押すと誤差に応じてスコアが獲得できます。
* 「現在の選択合計」に用いられる数字は「元年の西暦」です。
- 制限時間は90秒です。
